# 🇺🇦 ОВДП Portfolio Manager

Streamlit-застосунок для аналізу ринку та управління портфелем облігацій внутрішньої державної позики України (ОВДП).

## Встановлення і запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Структура проєкту

```
ovdp_app/
├── app.py                    # Головний Streamlit-застосунок
├── requirements.txt
└── modules/
    ├── bond_math.py          # Розрахунки: YTM, дюрація, DV01, Convexity, НКД
    ├── data_parser.py        # Парсинг ICU-тексту та ovdp.xlsx
    ├── portfolio.py          # Портфельна аналітика
    ├── glossary.py           # Бібліотека термінів
    └── icu_default.txt       # Зразок ICU-повідомлення
```

## Вкладки

### 📊 Ринок ОВДП
- Таблиця котирувань ICU з розрахованими метриками
- Крива дохідності (yield curve) ICU продає / купує
- Графік Дюрація vs YTM
- Фільтри за роком погашення та діапазоном YTM

### 💼 Мій Портфель
- Введення позицій: ISIN + кількість + середня ціна купівлі
- Розрахунок ринкової вартості, НКД, нереалізованого P&L
- Агрегати: Weighted Average YTM, дюрація, DV01 портфеля
- Графіки: дюрація позицій, розподіл портфеля (pie chart)

### 📚 Бібліотека
- Пояснення 19 ключових термінів з формулами
- Пошук по термінах та визначеннях
- Зведена таблиця зв'язків метрик

## Методологія розрахунків

| Метрика | Метод |
|---------|-------|
| YTM | Метод Брента (ітераційний, actual/365) |
| SIM | Проста ставка, дисконтування кожного CF окремо |
| НКД | actual/365 від останнього купону |
| Дюрація Макколея | Зважені PV грошових потоків |
| Мод. дюрація | D_mac / (1 + YTM) |
| DV01 | Dirty Price × D_mod × 0.0001 |
| Convexity | Стандартна формула з t(t+1) |
