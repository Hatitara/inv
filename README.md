# 🇺🇦 ОВДП Portfolio Manager

Streamlit-застосунок для аналізу ринку, управління портфелем та ребалансування облігацій внутрішньої державної позики України (ОВДП).

## Встановлення і запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Структура проєкту

```
ovdp_app/
├── app.py                    # Головний Streamlit-застосунок
├── requirements.txt
└── modules/
    ├── bond_math.py          # Розрахунки: YTM, дюрація, DV01, Convexity, НКД
    ├── data_parser.py        # Парсинг ICU-тексту та ovdp.xlsx
    ├── portfolio.py          # Портфельна аналітика
    ├── glossary.py           # Бібліотека термінів
    └── icu_default.txt       # Зразок ICU-повідомлення
```

## Джерела даних

| Джерело | Що дає | Як завантажити |

### 🧠 Аналіз та Рекомендації

Головний аналітичний модуль. Базується на поточному портфелі та заданому профілі інвестора.

#### Профіль інвестора (вхідні параметри)

| Параметр | Що задає |
|----------|----------|
| Головна мета | Максимальний дохід / Баланс / Мінімальний ризик |
| Горизонт інвестування | Скільки років ви плануєте тримати облігації |
| Толерантність до ризику | Верхня межа дюрації кандидатів (0.8 / 1.8 / 5.0 рок.) |
| Цільова дохідність (YTM/SIM) | Мінімально прийнятний рівень ставки |
| Уникати «Гнучкий ФІКС» | Виключає з рекомендацій папери зі змінною ставкою |

#### Діагностика позицій

Кожна позиція перевіряється на відповідність профілю:
- YTM нижче цільового (з допуском −0.5%)
- Дюрація перевищує ліміт ризику або горизонт інвестора
- Погашення менш ніж за 3 місяці (ризик реінвестування)
- Наявність «Гнучкий ФІКС» при увімкненому фільтрі
- Суттєвий нереалізований збиток (> −₴50)

#### Алгоритм ребалансування (pool-based)

1. **Крок 1 — Продаємо**: всі позиції з прапорами об'єднуються в єдиний грошовий пул (сума ринкових вартостей).
2. **Крок 2 — Вибираємо кандидатів**: з ринку ICU фільтруються облігації, яких немає в портфелі, з YTM ≥ (ціль −1%), дюрацією ≤ `min(ліміт ризику, горизонт × 1.1)`, без гнучкого ФІКСУ (якщо увімкнено). Кожен кандидат отримує оцінку:
   - **YTM score (60%)** — наскільки ставка перевищує цільову
   - **Duration score (40%)** — наскільки дюрація близька до `горизонт × 0.8`
3. **Крок 3 — Розподіл пулу**: топ-5 кандидатів за оцінкою. Кошти розподіляються пропорційно до оцінки. Кількість облігацій округлюється вниз до цілого (залишок = нерозміщений залишок).
4. **Прогноз**: "здорові" позиції залишаються без змін, проблемні замінюються новими. Показуються порівняльні метрики До/Після.

#### Стрес-тест відсоткового ризику

Розраховує зміну вартості портфеля при паралельному зсуві кривої дохідності за формулою:

```
ΔP ≈ −D_mod × ΔY + ½ × Convexity × (ΔY)²
```

Інтерактивний слайдер від −300 до +300 б.п. з графіком повної shock curve.

#### Календар погашень і реінвестування

Гістограма очікуваних надходжень від погашень по місяцях. Для облігацій, що гасяться протягом наступних 12 місяців, автоматично пропонуються топ-5 об'єктів реінвестування з ринку ICU.

## Методологія розрахунків

| Метрика | Метод |
|---------|-------|
| YTM | Метод Брента (ітераційний, actual/365) |
| SIM | Проста ставка, дисконтування кожного CF окремо за `CF / (1 + SIM × t)` |
| НКД | actual/365 від дати останнього купону |
| Дюрація Макколея | `Σ [t × PV(CF_t)] / Dirty Price` |
| Модифікована дюрація | `D_mac / (1 + YTM)` |
| DV01 | `Dirty Price × D_mod × 0.0001` |
| Convexity | `Σ [t(t+1) × PV(CF_t)] / [Dirty Price × (1+YTM)²]` |
| Стрес-тест ΔP | `−D_mod × ΔY + ½ × Convexity × (ΔY)²` |
| Weighted Avg YTM | `Σ (YTM_i × MV_i) / Σ MV_i` |
